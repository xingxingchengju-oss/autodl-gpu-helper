# AutoDL GPU 抢卡助手

选中一台已有的 AutoDL 实例，让脚本自动等待空闲 GPU、尝试开机，并在实例进入“运行中”后提醒你。

**当前版本 v1.0.1 · 支持 Windows / macOS · 使用 Chrome + Tampermonkey（篡改猴）**

> 点击“开始抢卡”后，脚本会自动确认目标实例的正常 GPU 开机。开机后按 AutoDL 规则计费。等待期间请保持电脑唤醒、浏览器运行和账号登录。

## Windows 安装

1. **准备浏览器。** 使用 Google Chrome，在 Tampermonkey 官网选择 Chrome 版本并安装扩展。[Chrome 下载](https://www.google.com/chrome/) · [Tampermonkey 官网](https://www.tampermonkey.net/)
2. **开启脚本权限。** 在地址栏输入 `chrome://extensions/`，打开 Tampermonkey 的“详情”，开启“允许用户脚本”。较旧的 Chrome 按扩展提示开启“开发者模式”即可。
3. **下载项目。** 在本仓库首页点击 **Code → Download ZIP**，下载后右键 ZIP，选择“全部解压缩”。
4. **复制脚本。** 用记事本打开 `autodl-gpu-helper.user.js`，按 `Ctrl+A` 全选，再按 `Ctrl+C` 复制。
5. **保存到篡改猴。** 点击 Chrome 工具栏的 Tampermonkey 图标 →“添加新脚本”，按 `Ctrl+A`、`Ctrl+V` 替换默认代码，再按 `Ctrl+S` 保存。
6. **打开 AutoDL。** 登录容器实例列表，按 `Ctrl+R` 刷新。右下角出现 **AutoDL GPU 抢卡助手 v1.0.1** 就安装好了。[打开实例列表](https://www.autodl.com/console/instance/list)

## macOS 安装

1. **准备浏览器。** 使用 Google Chrome，在 Tampermonkey 官网选择 Chrome 版本并安装扩展。[Chrome 下载](https://www.google.com/chrome/) · [Tampermonkey 官网](https://www.tampermonkey.net/)
2. **开启脚本权限。** 在地址栏输入 `chrome://extensions/`，打开 Tampermonkey 的“详情”，开启“允许用户脚本”。较旧的 Chrome 按扩展提示开启“开发者模式”即可。
3. **下载项目。** 在本仓库首页点击 **Code → Download ZIP**，在 Finder 中双击 ZIP 解压。
4. **复制脚本。** 右键 `autodl-gpu-helper.user.js` →“打开方式”→“文本编辑”，按 `⌘A` 全选，再按 `⌘C` 复制。已有代码编辑器也可以使用。
5. **保存到篡改猴。** 点击 Chrome 工具栏的 Tampermonkey 图标 →“添加新脚本”，按 `⌘A`、`⌘V` 替换默认代码，再按 `⌘S` 保存。
6. **打开 AutoDL。** 登录容器实例列表，按 `⌘R` 刷新。右下角出现 **AutoDL GPU 抢卡助手 v1.0.1** 就安装好了。[打开实例列表](https://www.autodl.com/console/instance/list)

找不到 Tampermonkey 图标时，点击 Chrome 右上角拼图形状的“扩展程序”按钮即可。

## 怎么使用

1. **选实例。** 让目标实例显示在当前页，在助手下拉框中选择它，核对显卡型号和完整实例 ID。也可以直接粘贴完整 ID。
2. **设间隔。** 默认每 **10 秒**检查一次，最小 **5 秒**。等待期间如果目标变为“GPU充足”，脚本会立即尝试开机。遇到网络异常或限流时，会适当延长等待。
3. **点开始。** 点击“开始抢卡”，出现通知授权提示时选择“允许”。
4. **等结果。** “等待资源”表示继续等卡，“等待启动”表示开机结果还在确认。看到 **“抢卡成功”**，表示脚本已确认实例进入“运行中”。展开“最近记录”可以查看进度。

每次任务处理一台已有实例。它等待的是这台实例所属主机的空闲 GPU，可用资源仍可能被其他用户先占用，遇到缺卡会继续尝试。

## 怎么停止

点击 **“停止 / 接管”**，或按 **Esc** 即可停止。脚本会读取一次当前状态，并显示读取时间。

**已经提交给 AutoDL 的开机请求仍会继续处理。** 如果随后开机成功，实例会照常计费。

点击网页上的实例操作、弹窗、分页或筛选控件，也会触发人工接管。点击空白处或列表刷新按钮会保留任务。同一标签页整页刷新后，活跃任务会先核对状态再继续。

## 抢到后怎么通知

- **页面提醒** — 助手显示“抢卡成功”。
- **桌面提醒** — Chrome 发送“AutoDL GPU 已运行”通知，内容包含实例 ID。

首次使用建议检查以下设置。

| 设置位置 | 怎么设置 |
| --- | --- |
| Chrome，两种系统通用 | AutoDL 地址栏左侧的网站信息 → 网站设置 → 通知 → 允许 |
| Windows | 设置 → 系统 → 通知，允许 Google Chrome 通知和横幅。Windows 10 中可能叫“通知和操作” |
| macOS | 系统设置 → 通知 → Google Chrome，开启“允许通知”并选择横幅或提醒 |

请同时检查 Windows 的“请勿打扰 / 专注助手”或 macOS 的“专注模式”。后台标签页或电脑休眠可能延迟提醒。

当前版本在通知权限不足或发送失败时会跳过桌面提醒，之后授权也没有补发。任务停止后，实例随后启动时的成功观察也已结束。排查时先看面板是否显示过“抢卡成功”。

## 常见问题

**安装了却看不到面板？**

确认 Tampermonkey 和脚本都已启用、脚本权限已开启，然后回到 AutoDL 容器实例列表刷新网页。

**显示“GPU充足”，为什么还没抢到？**

先核对提示属于你选中的实例，再看“最近记录”。资源可能被抢先占用，也可能正在开机或等待网络重试。如果显示“已暂停”，按面板提示处理后重新开始。

**如何更新脚本？**

先停止任务，在 Tampermonkey 管理面板中编辑已有脚本，用新版文件的全部代码替换并保存。刷新 AutoDL，确认面板版本号后重新开始。
