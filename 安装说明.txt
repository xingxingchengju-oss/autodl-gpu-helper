AutoDL GPU 抢卡助手
版本 1.1.0

从旧版本更新

先在 AutoDL 助手面板点击“停止 / 接管”。打开 Tampermonkey 管理面板，编辑已有的“AutoDL GPU 抢卡助手”，用同目录 autodl-gpu-helper.user.js 的全部内容替换旧代码并保存。随后刷新 AutoDL 网页，确认助手标题显示 v1.1.0，核对完整实例 ID 后点击“开始抢卡”。

本次新增 1～3 台实例选择。助手观察全部所选实例，逐台处理正常 GPU 开机，当前启动结果确认后继续其他目标。每台成功后分别通知，所有目标完成后结束。面板显示每台状态、尝试次数和总体完成数量。

一、安装

1. 在 Chrome 安装 Tampermonkey。可从其官网选择 Chrome 版本并前往扩展商店。
   https://www.tampermonkey.net/

2. 打开 Chrome 的扩展程序管理页，进入 Tampermonkey 的详情，开启“允许用户脚本”。旧版 Chrome 可按 Tampermonkey 指引开启“开发者模式”。两种方式依浏览器版本选择。
   官方权限说明 https://www.tampermonkey.net/faq.php?q=Q209

3. 点击 Tampermonkey 图标，选择“添加新脚本”。用文本编辑器打开同目录的 autodl-gpu-helper.user.js，全选复制。将 Tampermonkey 编辑器中的默认内容全部替换为这份脚本，保存并启用。

4. 登录 AutoDL，打开容器实例列表并刷新网页。右下角会显示“AutoDL GPU 抢卡助手”。
   https://www.autodl.com/console/instance/list

二、使用

1. 在“要抢几台实例”中选择 1、2 或 3 台，分别选择不同实例或粘贴完整 ID。全部目标需要显示在当前分页中。“读取列表”只读取当前页面显示的实例。
2. 检查间隔默认 10 秒，最小 5 秒，用于定时刷新。等待资源时，目标实例变为“GPU充足”且正常开机按钮可用，会提前触发开机检查。网络异常与限流退避期间遵守等待时间。面板同时显示显卡型号、主机名称和完整 ID，便于核对。
3. 点击“开始抢卡”。该操作允许脚本自动确认所选实例的正常 GPU 开机，开机后按 AutoDL 规则计费。
4. 保持电脑唤醒、浏览器运行及账号登录。Chrome 对后台标签页的节流可能延后检查时间。
5. 面板显示“运行中”经核验后报告“抢卡成功”。桌面通知需要浏览器授权，结果也会保留在面板中。

现有实例等待的是所属主机的 GPU 资源。普通缺卡时持续等待，有资源后尝试开机。若开机检查发现资源已被占用，脚本只关闭经精确匹配的缺卡提示中的“我知道了”取消按钮，随后继续等待。

三、停止与人工接管

点击“停止 / 接管”会立即撤销助手的自动操作许可，结束后续刷新、开机提交和弹窗确认任务。

停止时对每台所选实例额外读取一次页面当前显示的状态，并记录时间。这是当前页面的快照。最近提交的请求结果尚未体现在页面时，会显示“结果待确认”。已提交到 AutoDL 的开机请求继续由服务器处理，实例之后仍可能启动并计费。

点击实例操作按钮、弹窗按钮、分页、筛选或其他交互控件，以及对这些控件按 Enter 或空格，会触发人工接管。Escape 也会停止自动化。点击页面空白处或实例列表的刷新按钮会保留当前任务。收起面板后，停止按钮仍然可用。

如果停止发生在“准备开机”阶段，本站正在进行的检查稍后仍可能弹出确认框。再次开启自动化前，按提示刷新网页，结束旧检查的回调，保证新弹窗与目标实例的关联。

AutoDL 页面自带的自动更新可能继续发生。面板中的停止控制助手发起的动作。

四、续跑和异常

同一标签页完整刷新后，正在进行的任务会先重新核对目标状态再继续。手动停止会清除续跑标记。重新打开页面或复制标签页后，手动点击开始。

每个任务只有一个进行中的开机尝试。同一浏览器配置文件、同一网站来源下，通过 Web Locks 互斥运行助手。另一个标签页会显示锁占用提示。

网络异常或限流时按设定间隔逐步加倍等待，退避通常最高 120 秒。用户设定的间隔大于 120 秒时，以该设定作为最小等待时间。恢复后回到设定间隔。

提交后持续核对状态。实例处于“开机中”时持续等待。已经提交但在 120 秒后仍显示“已关机”且结果无法确认时，会暂停并提示人工核对。

登录失效、余额不足、实例异常、目标缺失、重复 ID、表格改版或未知弹窗都会暂停任务。处理原因后重新开始即可。分页和筛选需要保证完整目标 ID 对应的实例仍显示在当前页。

自动确认白名单仅包含目标实例的正常 GPU 开机。无卡模式、克隆、重置、释放、更换镜像以及其他未识别操作均交由人工处理。缺卡说明中的取消按钮有独立的精确匹配规则。

五、熄屏与睡眠

屏幕关闭且电脑保持唤醒时，脚本通常继续运行，后台检查可能延迟。电脑睡眠或休眠时脚本暂停，唤醒后才恢复检查。笔记本合盖通常会进入睡眠，建议保持开盖。

macOS 可在终端运行 caffeinate -i，并保持终端窗口打开，以阻止空闲睡眠。屏幕仍可正常熄灭，结束时按 Control+C。手动睡眠或合盖仍可能中断运行。

Windows 可在“设置 → 系统 → 电源和电池”设置屏幕按时关闭、接通电源时睡眠为“从不”。Windows 10 通常在“电源和睡眠”。

建议接通电源，并在 Chrome“设置 → 性能”中将 autodl.com 加入“始终保持这些网站处于活动状态”。
